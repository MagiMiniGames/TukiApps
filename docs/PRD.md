# TukiApps — Product Requirements Document (v0.1)

**Principle:** Super Beneficial Only • Omnibeneficencia 100/100  
**Platforms:** Web + Mobile (iOS & Android) from day one  
**Builder:** AI-powered (natural language → working app)

## Vision

TukiApps is a social discovery network, app store, and AI-powered creation platform. People share apps they love. The system recommends apps they might truly like. Anyone can describe a beneficial app in plain language and the AI builds a clean version ready to publish. Ownership can be verified on HulosChain. The platform lives both standalone and as a living Magia interface inside TukiLifeParadise.

## Primary Goals

- Make beneficial app discovery social and human
- Make app creation accessible through AI
- Protect creator ownership (optional HulosChain verification)
- Maintain a permanently beneficial-only environment

## Target Users

- Everyday people seeking better apps
- Creators who want to share and build
- Builders who want idea → published app quickly
- TukiLifeParadise community members

## Core User Journeys

1. **Discover & Share**  
   Open feed → see shared apps → save / follow / share why you like an app → receive “Apps you might like”

2. **Explore Store**  
   Browse or search → open app page → view details, ratings, creator → Install / Open

3. **Create with AI**  
   Open Builder → describe the app in plain language → AI generates working version → refine visually → publish (optional HulosChain ownership record)

4. **Creator Flow**  
   Manage published apps, view shares & feedback, update versions

## Feature Requirements

### Social Layer
- Home feed of shared apps
- “Apps you might like” recommendations
- Ability to share an app with short text + screenshots
- Collections / lists
- Follow creators
- Soft social reactions (no toxic engagement mechanics)

### Store Layer
- App detail pages (screenshots, description, ratings, creator, install)
- Search + categories
- Beneficial-only filter (always active)
- Creator profiles

### AI App Builder
- Natural language input
- Live preview generation
- Beneficial-only templates and constraints
- Visual refinement tools
- One-click publish
- Versioning

### Ecosystem Integration
- Appears inside TukiLifeParadise Wall Computers
- Optional HulosChain ownership attestation
- Materialization-ready (apps can be referenced by Magias)

## High-Level Data Model

- Users (profile, preferences, beneficial signals)
- Apps (metadata, screenshots, versions, ownership proof)
- Shares (user + app + text + media)
- Collections
- Recommendation signals
- Builder sessions / generated apps

## Non-Functional Requirements

- Privacy-respecting by default
- No dark patterns or attention extraction
- Fast, calm, beautiful interface
- Cross-platform consistency
- Only Super Beneficial Only apps allowed

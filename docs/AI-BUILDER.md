# TukiApps — AI App Builder Overview

## Goal

Allow any user to describe a beneficial app in natural language and receive a working, publishable version with live preview and refinement tools.

## Core Flow

1. **Input**  
   User types a clear description (e.g. “A calm habit tracker focused on daily gratitude with soft tropical visuals and private local storage”).

2. **Intent Extraction**  
   LLM pipeline extracts:
   - Core purpose
   - Main screens
   - Data needs
   - Interactions
   - Visual style preferences
   - Beneficial constraints

3. **Constraint Application**  
   Only Super Beneficial Only patterns are allowed. Dark patterns, addictive mechanics, or harmful data practices are rejected or rewritten.

4. **Generation**  
   - UI components
   - Basic navigation
   - Data model
   - Simple logic / state

5. **Live Preview**  
   User sees an interactive preview immediately.

6. **Refinement**  
   Visual editor + further natural language adjustments.

7. **Publish**  
   One-click publish to TukiApps store. Optional HulosChain ownership record.

## Principles

- Beneficial by default
- Transparent generation
- User remains the owner of the creation
- Simple enough for non-developers, powerful enough for real use

## Future Extensions

- Template library of proven beneficial patterns
- Community-shared builder prompts
- Direct Magia / Wall Computer materialization hooks

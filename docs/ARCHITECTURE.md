# TukiApps — Technical Architecture

## High-Level Architecture

## Recommended Stack

| Layer              | Recommendation                          | Reason |
|--------------------|-----------------------------------------|--------|
| Cross-platform UI  | Flutter **or** React Native + Expo     | True day-one web + mobile |
| Web                | Next.js (if React) or Flutter web      | Fast, SEO-friendly store |
| Backend            | Node.js (NestJS) or Python (FastAPI)   | Strong AI integration |
| Database           | PostgreSQL + Redis                     | Reliable + fast feeds |
| AI Builder         | Structured LLM pipeline                | Controllable & beneficial |
| Auth               | Secure email / social + optional wallet| Simple + sovereignty option |
| Media              | Cloud object storage                   | Screenshots & assets |
| Blockchain         | HulosChain integration layer           | Ownership & verification |
| Hosting            | Scalable cloud with edge               | Global performance |

## AI App Builder Approach

1. User writes natural language description
2. System extracts structured intent (screens, data, actions, style)
3. Applies Super Beneficial Only constraints and templates
4. Generates UI + basic logic + data model
5. Shows live preview
6. User refines → final publish package is created

## Cross-Platform Strategy

- Single codebase priority (Flutter currently strongest for true web + mobile consistency)
- Progressive Web App as the universal entry point
- Native shells for app store distribution later

## HulosChain Integration Points

- Creator identity attestation
- App ownership / version records
- Optional value-flow contracts later
- Verification badges shown in the UI
